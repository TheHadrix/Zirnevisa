# 🎬 پروژه زیرنویسا (ZirNovisa)
### سامانه هوشمند ترجمه آنلاین زیرنویس فیلم و سریال با Mistral AI

پروژه **زیرنویسا** یک وب‌اپلیکیشن تک‌سرویس، مدرن و سریع با فریم‌ورک **FastAPI** است که با هوش مصنوعی فایل‌های زیرنویس `.srt` را با حفظ دقیق زمان‌بندی (Timing) و استخراج اصطلاحات محاوره‌ای به زبان فارسی ترجمه می‌کند.

---

## ✨ ویژگی‌های کلیدی

- **تک‌سرویس و سبک**: بدون نیاز به Redis یا Celery؛ پردازش‌های پس‌زمینه با `BackgroundTasks` اختصاصی FastAPI مدیریت می‌شوند.
- **دیتابیس خودکار**: SQLite + SQLAlchemy با قابلیت ساخت خودکار جداول هنگام استارت‌آپ (بدون نیاز به دستورات مایگریشن).
- **الگوریتم Fallback هوشمند کانفیگ‌ها**: قابلیت تعریف چندین کلید API و مدل Mistral با اولویت‌بندی (`priority_order`). در صورت بروز خطا در کلید اول، سیستم بلافاصله به کلیدهای بعدی سوئیچ می‌کند.
- **رابط کاربری شیشه‌ای (Glassmorphism)**: طراحی زیبا با Tailwind CSS و فونت فارسی وزیرمتن (Vazirmatn).
- **تعامل زنده با HTMX و Alpine.js**: آپلود Drag & Drop، نوار پیشرفت با Polling دو ثانیه‌ای زنده بدون رفرش، و مودال خرید اشتراک ویژه.
- **سیستم اشتراک و سهمیه روزانه**:
  - سهمیه کاربر مهمان: حداکثر ۳ فایل در روز.
  - سهمیه کاربر ویژه (VIP): حداکثر ۱۰ فایل در روز.
  - ریست خودکار سهمیه در هر ۲۴ ساعت.
- **محدودیت کاراکتر و فرمت**: بررسی فرمت `.srt` و سقف حداکثر ۳۰,۰۰۰ کاراکتر متن زیرنویس.
- **حفظ حریم خصوصی و پاکسازی حافظه**: حذف خودکار فایل‌های اصلی و ترجمه شده بعد از ۲ دقیقه از روی دیسک.
- **درگاه پرداخت شبیه‌سازی شده**: امکان تست خرید اشتراک ۱ ماهه VIP و ارتقای آنی سهمیه.
- **پنل مدیریت (Admin Panel)**: مدیریت کاربران، وضعیت اشتراک‌ها و مدیریت کانفیگ‌ها و تست سلامت اتصال کلیدهای هوش مصنوعی.

## 🚀 راهنمای راه‌اندازی و اجرا

### ۱. نصب وابستگی‌ها
مطمئن شوید پایتون (نسخه ۳.۱۰ به بالا) روی سیستم شما نصب است، سپس دستور زیر را در ترمینال اجرا کنید:

```bash
pip install -r requirements.txt
```

### ۲. اجرای سرور
تنها با اجرای دستور زیر در پوشه پروژه، برنامه اجرا خواهد شد:

```bash
uvicorn main:app --reload
```

سپس مرورگر خود را باز کرده و به آدرس زیر بروید:
👉 **`http://127.0.0.1:8000`**

---

## 🔑 اطلاعات ورود به پنل ادمین (پیش‌فرض)

به محض اجرای اولیه، یک کاربر مدیر پیش‌فرض در دیتابیس ساخته می‌شود:
- **ایمیل**: `admin@zirnovisa.ir`
- **رمز عبور**: `admin123`
- **آدرس پنل ادمین**: `http://127.0.0.1:8000/admin`

> 💡 **نکته**: برای شروع ترجمه واقعی با هوش مصنوعی، وارد پنل ادمین شوید و در تب "کانفیگ‌های هوش مصنوعی (Mistral)" کلید معتبر خود را وارد کرده و وضعیت آن را فعال کنید.

## 📁 ساختار پوشه‌بندی پروژه

```text
Zirnevisa/
├── app/
│   ├── config.py              # تنظیمات، سکرت JWT و محدودیت‌ها
│   ├── database.py            # تنظیمات SQLAlchemy و اتصال دیتابیس
│   ├── models.py              # جداول User, ProviderConfig, TranslationTask, GuestUsage
│   ├── schemas.py             # کلاس‌های اعتبارسنجی داده Pydantic
│   ├── auth.py                # مدیریت توکن‌های JWT و کوکی‌های امن
│   ├── services/
│   │   ├── srt_processor.py   # پارسر و بازسازنده SRT و تقسیم‌بندی بلاک‌ها
│   │   ├── mistral_service.py # اتصال به Mistral و الگوریتم Failover/Fallback
│   │   └── cleanup_service.py # حذف خودکار فایل‌ها بعد از ۲ دقیقه
│   ├── routes/
│   │   ├── pages.py           # رندر صفحات HTML با Jinja2
│   │   ├── auth_routes.py     # لاگین، ثبت‌نام و خروج
│   │   ├── translation_routes.py # آپلود، محاسبه پیشرفت و دانلود
│   │   ├── payment_routes.py  # شبیه‌ساز پرداخت و ارتقای سهمیه
│   │   └── admin_routes.py    # مدیریت کاربران و کانفیگ‌های هوش مصنوعی
│   ├── templates/             # قالب‌های تعاملی با HTMX و Alpine.js
│   └── static/                # استایل‌های شیشه‌ای و فایل‌های موقت
├── main.py                    # فایل اصلی و هندلر Lifespan
├── requirements.txt           # لیست کتابخانه‌های پایتون
└── README.md                  # راهنمای پروژه
```
