## 📖 درباره پروژه

**زیرنویسا (Zirnevisa)** یک پلتفرم بومی و مدرن مبتنی بر فریم‌ورک قدرتمند **Django 5** است که برای ترجمه طبیعی، سریع و باکیفیت فایل‌های زیرنویس (`.srt`) توسعه یافته است. این سامانه با تلفیق پرامپت‌های مهندسی‌شده سینمایی و الگوریتم‌های هوشمند پردازش متن، زیرنویس‌ها را دقیقاً با همان لحن صمیمی، گفتاری و روانِ مترجمان برتر وب فارسی ترجمه می‌کند.

---

## ✨ ویژگی‌های برجسته و قابلیت‌های کلیدی

### ۱. کیفیت ترجمه انسانی و محاوره‌ای (Master Subtitle Prompt)
- **لحن گفتاری و زنده:** ترجمه تخصصی با افعال و ضمایر شکسته متداول در دوبله و زیرنویس ایرانی («می‌خوام»، «نمی‌ذارم»، «باهاشون»، «رو»، «یه»، «بخوابه»).
- **معادل‌سازی اصطلاحات و اسلنگ‌ها:** درک کنایه‌ها، طنزها، هیجان و اصطلاحات روز انگلیسی به معادل‌های رایج فارسی.
- **حفظ ۱۰۰٪ ساختار زیرنویس:** ماندگاری تگ‌های استایل `<i>...</i>`، تراز و موقعیت زیرنویس `{\an8}`، شکست خطوط `[BR]` و تایم‌کدهای دقیق میلی‌ثانیه‌ای بدون کوچک‌ترین ناهماهنگی زمانی.

### ۲. سیاست قطعی «یک فایل = یک مدل اختصاصی» (Single-Model-Per-File Policy)
- **یکدستی کامل لحن:** هر فایل زیرنویس از سطر اول تا آخرین سطر، منحصراً توسط **یک مدل مشخص** ترجمه می‌شود.
- **توقف در صورت خطا بدون دورگه شدن:** در صورت بروز خطا در مدل منتخب، سیستم هرگز به مدل دیگری سوییچ نمی‌کند تا لحن دیالوگ‌ها در میانه فیلم دوگانه یا ناموزون نشود.
- **شفافیت کامل:** نام دقیق مدل ترجمه‌کننده روی کارت هر تسک نمایش داده می‌شود.

### ۳. چانک‌بندی داینامیک بر اساس توان مدل (Dynamic Chunk Sizing)
- **Google Gemini (تا ۳۸,۰۰۰ کاراکتر):** بهره‌برداری حداکثری از سقف خروجی ۶۴K توکن جهت ترجمه یک فیلم ۲.۵ ساعته سینمایی در تنها ۲ چانک با انسجام روایی بی‌نظیر.
- **Mistral AI (تا ۱۸,۰۰۰ کاراکتر):** بهینه‌سازی شده بر اساس سقف خروجی ۱۶K توکن میسترال به همراه لایه محافظتی Auto-Subchunking جهت پیشگیری از خطاهای سرریز توکن و خطای ۴۲۹.

### ۴. رابط کاربری مدرن و واکنش‌گرا (UI/UX)
- **طراحی شیشه‌ای لوکس (Glassmorphism):** همراه با حالت تاریک/روشن (Dark/Light Mode)، انیمیشن‌های میکرو و فونت خوانای وزیرمتن (Vazirmatn).
- **تعاملات زنده با HTMX:** قابلیت Drag & Drop فایل‌ها، محاسبه آنی تعداد کاراکترها و مشاهده پیشرفت درصد ترجمه به صورت زنده با Polling دو ثانیه‌ای بدون رفرش صفحه.

### ۵. مدیریت دسترسی و سهمیه‌بندی روزانه
- **کاربران مهمان:** تا ۳ فایل زیرنویس در روز (با پاکسازی خودکار فایل‌ها بعد از ۵ دقیقه جهت حفظ حریم خصوصی و مدیریت دیسک).
- **کاربران ویژه (VIP):** تا ۱۰ فایل در روز با نگهداری دائمی فایل‌های ترجمه‌شده در داشبورد اختصاصی.
- **ریست خودکار ۲۴ ساعته سهمیه‌ها** بر اساس تاریخ تقویم محلی.

### ۶. پنل مدیریت حرفه‌ای و ابزار خودکار کشف مدل‌ها
- **داشبورد مدیریت پیشرفته:** مشاهده لیست کاربران، تسک‌ها و مدیریت ارائه‌دهندگان هوش مصنوعی با قابلیت جابجایی اولویت‌ها (Drag & Drop)، تست زنده اتصال و فعال/غیرفعال‌سازی.
- **ابزار CLI کشف خودکار (`commands/auto_discover_providers.py`):** تست خودکار پینگ، سنجش تاخیر (Latency) و ثبت اتوماتیک بیش از ۵۰ مدل در دسترس Google Gemini و Mistral AI.

## 📁 ساختار پوشه‌بندی و معماری پروژه

```text
Zirnevisa/
├── apps/
│   ├── accounts/              # مدیریت کاربران، اعتبارسنجی، OTP و سطوح VIP
│   │   ├── models.py          # مدل سفارشی User و سیستم سهمیه روزانه
│   │   ├── views.py           # ثبت‌نام، ورود، خروج و ارسال کد تایید
│   │   └── urls.py            # روت‌های احراز هویت
│   └── translations/          # موتور اصلی پردازش و ترجمه زیرنویس
│       ├── models.py          # جداول ProviderConfig, TranslationTask, GuestUsage
│       ├── views.py           # پردازش پس‌زمینه، آپلود، وضعیت HTMX، داشبورد و ادمین‌پنل
│       └── services/
│           ├── srt_processor.py   # پارسر Regex، شمارنده کاراکتر و چانک‌بندی SRT
│           ├── llm_service.py     # اتصالات امن API، پرامپت طلایی و لایه محافظ میسترال
│           └── cleanup_service.py # پاکسازی زمان‌بندی‌شده فایل‌های موقت
├── commands/
│   └── auto_discover_providers.py # ابزار CLI کشف و ثبت خودکار مدل‌های AI
├── core/
│   ├── settings.py            # پیکربندی متمرکز جنگو، چانک‌ها و سهمیه‌ها
│   ├── urls.py                # روت‌های اصلی سامانه
│   └── wsgi.py / asgi.py      # اینترفیس‌های وب‌سرور
├── static/                    # فایل‌های استاتیک، فونت Vazirmatn و استایل‌ها
├── templates/                 # قالب‌های مدرن Jinja/Django، کامپوننت‌های HTMX و Alpine
├── tests/                     # فایل‌های نمونه و تست‌های پایداری
│   └── subtitles/             # زیرنویس‌های مرجع جهت بنچمارک و ارزیابی
├── manage.py                  # اینترفیس خط فرمان جنگو
├── requirements.txt           # لیست کتابخانه‌های پایتون
└── README.md                  # مستندات و راهنمای پروژه
```

## 🚀 راهنمای نصب و اجرای پروژه

### پیش‌نیازها
* پایتون نسخه **۳.۱۰** یا بالاتر
* دسترسی به اینترنت (جهت ارتباط با APIهای هوش مصنوعی)

### ۱. کلون کردن ریپازیتوری
```bash
git clone https://github.com/TheHadrix/Zirnevisa.git
cd Zirnevisa
```

### ۲. ساخت و فعال‌سازی محیط مجازی (Virtualenv)
```bash
# در ویندوز:
python -m venv .venv
.venv\Scripts\activate

# در لینوکس / مک:
python3 -m venv .venv
source .venv/bin/activate
```

### ۳. نصب کتابخانه‌ها
```bash
pip install -r requirements.txt
```

### ۴. تنظیم متغیرهای محیطی (`.env`)
یک فایل به نام `.env` در ریشه پروژه بسازید یا مقادیر زیر را در آن تنظیم کنید:

```env
SECRET_KEY=your-super-secret-django-key
DEBUG=True
ALLOWED_HOSTS=*

# تنظیم سقف چانک‌ها (اختیاری - پیش‌فرض‌های بهینه تنظیم شده است)
GEMINI_CHUNK_MAX_CHARS=38000
MISTRAL_CHUNK_MAX_CHARS=18000
```

### ۵. اجرای مایگریشن‌ها و ساخت دیتابیس
```bash
python manage.py migrate
```

### ۶. ایجاد کاربر مدیر (Superuser)
```bash
python manage.py createsuperuser
```

### ۷. اجرای سرور توسعه
```bash
python manage.py runserver
```

حالا مرورگر خود را باز کرده و وارد سامانه شوید:
👉 **`http://127.0.0.1:8000`**

## ⚙️ مدیریت و تنظیم ارائه‌دهندگان هوش مصنوعی

شما به دو روش می‌توانید مدل‌های فعال هوش مصنوعی را در سیستم اضافه و اولویت‌بندی کنید:

### روش اول: از طریق پنل مدیریت تحت وب (توصیه‌شده)
1. به آدرس `http://127.0.0.1:8000/admin-panel/` بروید و لاگین کنید.
2. در تب **«ارائه‌دهندگان هوش مصنوعی»**، مدل مورد نظر (`Google Gemini` یا `Mistral AI`) و کلید API مربوطه را وارد کنید.
3. با کلیک روی دکمه تست، سلامت اتصال را ارزیابی کرده و با قابلیت جابجایی ماوس (Drag & Drop)، اولویت مدل‌ها را مشخص کنید.

### روش دوم: با اسکریپت خودکار کشف مدل‌ها (CLI)
برای پینگ دسته‌جمعی و ثبت آنی مدل‌های فعال در وب‌سایت:
```bash
python commands/auto_discover_providers.py
```
> این اسکریپت مدل‌های فعال را یکی‌یکی تست کرده و در صورت پاسخ‌دهی، آن‌ها را مستقیماً در دیتابیس سایت ثبت می‌کند.

## 🔒 متغیرهای کلیدی در `core/settings.py`

| متغیر | مقدار پیش‌فرض | توضیحات |
| :--- | :---: | :--- |
| `GEMINI_CHUNK_MAX_CHARS` | `38000` | سقف کاراکتر هر چانک برای مدل‌های Google Gemini |
| `MISTRAL_CHUNK_MAX_CHARS` | `18000` | سقف کاراکتر هر چانک برای مدل‌های Mistral AI |
| `CHAR_LIMIT` | `30000` | سقف مجاز کاراکترهای فایل برای آپلود توسط مهمانان |
| `GUEST_DAILY_LIMIT` | `3` | تعداد مجاز ترجمه فایل در روز برای کاربران مهمان |
| `VIP_DAILY_LIMIT` | `10` | تعداد مجاز ترجمه فایل در روز برای کاربران ویژه |
| `GUEST_CLEANUP_DELAY_SECONDS` | `300` | زمان حذف خودکار فایل‌های مهمان از سرور (۵ دقیقه) |
